# CloudCalm

CloudCalm is an AI-powered assistant that guides users through AWS troubleshooting one step at a time.

## Live Demo

https://d3k5tubm23r94c.cloudfront.net

## Features

- Guided AWS troubleshooting with interactive diagnostic choices.
- Beginner-friendly explanations and actionable steps.
- Structured responses generated by Amazon Bedrock.
- Serverless backend architecture.

## Architecture

- Amazon CloudFront serves the frontend over HTTPS.
- Amazon S3 stores the frontend assets.
- Amazon API Gateway exposes the troubleshooting endpoint.
- AWS Lambda processes requests.
- Amazon Bedrock generates troubleshooting guidance.
- Amazon CloudWatch captures Lambda execution logs.

The current prototype demonstrates guided investigation of HTTP 503 errors from an Application Load Balancer.

## Technology Stack

React, TypeScript, Vite, Python, AWS Lambda, Amazon API Gateway, Amazon Bedrock, Amazon S3, and Amazon CloudFront.

## Local Development

### Frontend

From the frontend directory, install dependencies:

    npm install

Create a local .env file containing:

    VITE_API_URL=https://4wjs1x3guj.execute-api.us-east-1.amazonaws.com/troubleshoot

Start the development server:

    npm run dev

Build the production frontend:

    npm run build

### Backend

The Lambda handler is in backend/lambda_function.py. It requires suitable AWS permissions to invoke the configured Amazon Bedrock inference profile.

Configure AWS credentials locally using your normal AWS CLI profile. Never commit credentials or secrets.

## Security and Limitations

CloudCalm provides guided troubleshooting based on user-provided observations. It does not independently inspect or modify AWS infrastructure.

Users should verify recommendations against their own environment before making changes.

This demo is a prototype. Authentication, abuse protection, request throttling, and additional security hardening should be considered before production use.
